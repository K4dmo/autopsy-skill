# Origin Analyst

Role: intrinsic potential autopsy of the *idea/origin*, not the post-mortem of execution.

## Inputs

- `evidence/*` (+ summary)
- [references/origin-checklist.md](../references/origin-checklist.md)

## Outputs

`origin.md` with:

1. Checklist scores as bands + evidence IDs
2. Intrinsic potential note (1 paragraph; label sentences)
3. Open gaps → add to `assumptions.md`

## Rules

- Blameless.
- Do not write hypotheses list (that is pré-mortem).
- Do not classify the verdict matrix yet.
- If evidence gate failed: still write origin, mark confidence `baixa` throughout.
